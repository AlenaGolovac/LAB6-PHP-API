
# Практична робота №6
## Контракт API — Система обліку студентів/оцінок

**Варіант:** 11  
**Ресурс:** students  
**Точка входу:** api.php  
**Формат відповідей:** JSON

### Структура даних

Таблиця students містить такі поля:
- id — унікальний ідентифікатор студента;
- name — ім'я студента;
- group_name — назва академічної групи;
- average_grade — середній бал студента.

### 1. GET — Отримання списку студентів

Метод: GET  
Ресурс: students  
Запит: /api.php?resource=students

Параметри: resource=students, id відсутній.

Опис: повертає список усіх студентів.

Код відповіді: 200 OK.

Приклад відповіді:

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Іван Петренко",
      "group_name": "ІО-41",
      "average_grade": 92.5
    },
    {
      "id": 2,
      "name": "Марія Коваль",
      "group_name": "ІО-41",
      "average_grade": 95.0
    }
  ]
}
```

### 2. GET — Отримання одного студента

Метод: GET  
Ресурс: students  
Запит: /api.php?resource=students&id=1

Параметри: resource=students, id=1.

Опис: повертає інформацію про студента за його id.

Коди відповіді:
- 200 OK — студент знайдений.
- 404 Not Found — студента не знайдено.

Приклад успішної відповіді:

```json
{
  "success": true,
  "data": {
    "id": 1,
    "name": "Іван Петренко",
    "group_name": "ІО-41",
    "average_grade": 92.5
  }
}
```

Приклад помилки:

```json
{
  "success": false,
  "error": "Студента не знайдено"
}
```

### 3. POST — Створення нового студента

Метод: POST  
Ресурс: students  
Запит: /api.php?resource=students

Параметри: resource=students, action відсутній.

Обов'язкові поля:
- name
- group_name
- average_grade

Приклад тіла запиту:

```json
{
  "name": "Олена Шевченко",
  "group_name": "ІО-42",
  "average_grade": 89.5
}
```

Коди відповіді:
- 201 Created — студента створено.
- 400 Bad Request — некоректні або відсутні дані.

Приклад відповіді:

```json
{
  "success": true,
  "data": {
    "id": 3,
    "name": "Олена Шевченко",
    "group_name": "ІО-42",
    "average_grade": 89.5
  }
}
```

### 4. POST — Студент із найвищим середнім балом

Метод: POST  
Ресурс: students  
Запит: /api.php?resource=students&action=top

Параметри:
- resource=students
- action=top
- group_name — назва поточної групи (у тілі запиту).

Опис: повертає студента з найвищим середнім балом у зазначеній групі.

Приклад тіла запиту:

```json
{
  "group_name": "ІО-41"
}
```

Коди відповіді:
- 200 OK — студент знайдений.
- 400 Bad Request — не вказано групу.
- 404 Not Found — у групі немає студентів.

Приклад відповіді:

```json
{
  "success": true,
  "data": {
    "id": 2,
    "name": "Марія Коваль",
    "group_name": "ІО-41",
    "average_grade": 95.0
  }
}
```

### 5. Обробка помилок

API повертає такі HTTP-коди:
- 200 OK — успішне отримання даних.
- 201 Created — успішне створення запису.
- 400 Bad Request — некоректні вхідні параметри.
- 404 Not Found — ресурс або запис не знайдено.
- 405 Method Not Allowed — метод не підтримується.

Приклад відповіді при непідтримуваному методі:

```json
{
  "success": false,
  "error": "Метод не підтримується"
}
```

Усі відповіді API мають узгоджену структуру:
- success — результат виконання запиту;
- data — отримані дані;
- error — опис помилки.
